# VSD - Visual Statistics Display

A Flutter desktop app for viewing and analyzing statmonitor data generated by GemStone/S 64 Bit, GemStone/S, or GBS. Use it to monitor performance and diagnose problems in complex GemStone systems. This is the Flutter-based successor to the Tcl/Tk [VSD 5.x](https://gemtalksystems.com/products/vsd/).

## Features

**File loading**
- Open `.out` and `.out.gz` files

**Process & statistics exploration**
- Browse loaded processes with start/end times and sample counts
- Drill into per-process statistics and view stat metadata: description, units, and min/max/avg values

**Charts**
- Plot any statistic as a line chart with a trackball tooltip for precise point inspection
- Compare multiple statistics side by side

**AI assistant**
- Ask natural-language questions about the loaded data
- Requires your own Anthropic API key

## Getting Started

```sh
flutter pub get
flutter run -d macos   # or -d windows / -d linux
```
